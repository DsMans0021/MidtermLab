Algebra · Topic 03 · Numerical Analysis

Numerical Analysis · التحليل العددي

Some equations cannot be solved exactly. Numerical methods find the root approximately. This page covers bisection, simple fixed-point iteration, and Newton–Raphson — with convergence, error, and exam-style examples.

بعض المعادلات مش بتتحل بالضبط. الطرق العددية بتجد الجذر تقريبيًا. الصفحة دي بتغطي التنصيف، النقطة الثابتة، ونيوتن–رافسون — مع التقارب والخطأ وأمثلة على شكل الامتحان.

1 · The idea

Bracketing and iteration

A root of f(x) = 0 is a value x where the graph crosses the x-axis. Numerical methods start with a guess (or an interval) and improve it repeatedly until the answer is accurate enough.

جذر f(x) = 0 هو قيمة x عندها الرسم يقطع محور x. الطرق العددية بتبدأ بتخمين (أو فترة) و بتحسّنه بتكرار لحد ما الدقة تكفي.

→

Intermediate value theorem · نظرية القيمة المتوسطة

If f is continuous on [a, b] and f(a)·f(b) < 0, then there is at least one root in (a, b). This is the starting condition for bisection.

لو f متصلة على [a, b] وf(a)·f(b) < 0، يبقى فيه جذر واحد على الأقل في (a, b). ده شرط البداية للتنصيف.

2 · Bisection

Halve the interval every time

Bisection formula
xr = (xl + xu) / 2
Replace the half where the sign does not change.

Choose xl and xu with opposite signs. Compute the midpoint xr. If f(xl)·f(xr) < 0, the root is in the lower half; set xu = xr. Otherwise set xl = xr. Repeat.

اختار xl وxu بإشارتين مختلفتين. احسب نقطة المنتصف xr. لو f(xl)·f(xr) < 0، الجذر في النصف السفلي؛ خلي xu = xr. غير كده خلي xl = xr. وكرر.

Example 1 · bisection

Use bisection to solve 2x³ − x² + 2x − 1 = 0 on [0, 1].

f(0) = −1 < 0, f(1) = 2 > 0 → root in [0,1] x1 = (0+1)/2 = 0.5 f(0.5) = 2(0.125) − 0.25 + 1 − 1 = 0 The root is exactly x = 0.5
!

Convergence · التقارب

Bisection always converges if the sign change exists, but it is slow (linear). The error is halved each iteration. It never uses the size of f(x), only its sign.

التنصيف بيتقارب دايمًا لو فيه تغير إشارة، لكنه بطيء (تقارب خطي). الخطأ بيقل للنصف كل تكرار. مبيستخدمش قيمة f(x)، بس إشارتها.

3 · Fixed-point iteration

Rewrite f(x) = 0 as x = g(x)

Fixed-point iteration
xn+1 = g(xn)
Converges if |g′(x)| < 1 near the root.

Rearrange the equation so x appears alone. Start with x₀, then iterate. The method converges when the derivative of g near the root is less than 1 in magnitude. If |g′| > 1, it diverges — choose a different rearrangement.

رتّب المعادلة بحيث x تبقى لوحدها. ابدأ بـx₀ وكرر. الطريقة بتتقارب لما |مشتقة g| قرب الجذر أقل من 1. لو |g′| > 1، بتتباعد — اختار ترتيب تاني.

Example 2 · fixed point

Solve x − e−x = 0 using x = e−x, starting at x₀ = 0.

x1 = e⁰ = 1 x2 = e−1 ≈ 0.3679 x3 = e−0.3679 ≈ 0.6922 x4 = e−0.6922 ≈ 0.5005 x5 = e−0.5005 ≈ 0.6062 Continues toward x ≈ 0.5671
4 · Newton–Raphson

Use the tangent line

Newton–Raphson formula
xn+1 = xn − f(xn) / f′(xn)
Requires f′(x) ≠ 0 and a good initial guess.

Newton–Raphson is usually the fastest method (quadratic convergence near the root). It needs the derivative and a starting point close to the root. A bad guess or a zero derivative can make it fail.

نيوتن–رافسون عادةً أسرع طريقة (تقارب تربيعي قرب الجذر). محتاج المشتقة ونقطة بداية قريبة من الجذر. تخمين وحش أو مشتقة صفر ممكن يخليها تفشل.

Example 3 · Newton–Raphson

Solve f(x) = x² − 2 = 0 starting at x₀ = 1.

f′(x) = 2x x1 = 1 − (1−2)/(2) = 1.5 x2 = 1.5 − (2.25−2)/(3) = 1.4167 x3 = 1.4167 − (2.0069−2)/(2.8333) ≈ 1.41422 Converges to √2 ≈ 1.41421

Exam strategy · استراتيجية الامتحان

If the question says “use bisection”, show the interval, midpoint, and sign check each iteration. If it says “use Newton”, write f′ first. If it says “fixed point”, show the rearrangement and check |g′|.

لو السؤال قال “استخدم التنصيف”، اكتب الفترة ونقطة المنتصف وفحص الإشارة كل تكرار. لو قال “نيوتن”، اكتب f′ الأول. ولو قال “نقطة ثابتة”، اكتب الترتيب واتأكد من |g′|.

Part II · 40 marks

المسائل · Problems

Show the method, not only the answer.

P1
Simplify (2 + 3i)/(1 − i).
Multiply by (1+i)/(1+i): numerator = (2+3i)(1+i) = 2+2i+3i+3i² = −1+5i; denominator = 2. Result = −1/2 + (5/2)i.
P2
Find (1 − i)⁴ using polar form or direct expansion.
1−i = √2 e−iπ/4. (1−i)⁴ = (√2)⁴ e−iπ = 4(−1) = −4.
P3
Find the quadratic equation whose roots are 1 + 2i and 1 − 2i.
Sum = 2; product = 1+4 = 5. Equation: x² − 2x + 5 = 0.
P4
If α, β are roots of x² − 6x + 4 = 0, find α² + β² and 1/α + 1/β.
α+β = 6, αβ = 4. α²+β² = 36−8 = 28. 1/α+1/β = (α+β)/(αβ) = 6/4 = 1.5.
P5
Use Newton–Raphson twice to approximate √5, starting at x₀ = 2. (f(x)=x²−5)
f′=2x. x₁ = 2 − (4−5)/4 = 2.25. x₂ = 2.25 − (5.0625−5)/4.5 = 2.23611.
P6
Solve by Gauss: x + 2y = 5; 3x − y = 1.
[1 2 | 5; 3 −1 | 1]. R2 → R2−3R1: [0 −7 | −14] → y = 2. Then x + 4 = 5 → x = 1. Solution: (1, 2).
Part III · 20 marks

أسئلة مقالية · Written

W1
State De Moivre's theorem and use it to explain why zⁿ has n distinct nth roots.
zⁿ = rⁿ[cos(nθ)+i sin(nθ)]. For roots, θ is replaced by (θ+2kπ)/n, k = 0,…,n−1; these n angles differ by 2π/n and give n distinct points on a circle.
W2
Explain the factor theorem and how synthetic division uses it.
f(c)=0 ⇔ (x−c) is a factor. Synthetic division evaluates f(c) and gives the quotient coefficients at the same time; a zero remainder proves the factor.
W3
Compare bisection, fixed-point iteration, and Newton–Raphson.
Bisection: guaranteed but slow, needs a sign change. Fixed point: needs x=g(x) with |g′|<1, linear. Newton: needs f′ and a good guess, quadratic and fastest near the root.
W4
List the elementary row operations and explain what a pivot is.
Swap rows; multiply a row by a nonzero constant; add a multiple of one row to another. A pivot is the first nonzero entry in a row used to eliminate entries below (or above) it.

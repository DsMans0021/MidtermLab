Complex Numbers · الأعداد المركبة

A complex number extends the real line with the imaginary unit i. This page covers algebra, conjugate, modulus, argument, polar form, De Moivre's theorem, and nth roots — the tools every later algebra topic depends on.

العدد المركب بيوسّع الخط الحقيقي بالوحدة التخيلية i. الصفحة دي بتغطي العمليات، المرافق، المقياس، السعة، الصورة القطبية، نظرية ديموافر، والجذور — الأدوات اللي كل مواضيع الجبر بعدها بتعتمد عليها.

1 · Definition

The imaginary unit and the complex plane

The imaginary unit is defined by i² = −1. A complex number is z = a + bi, where a is the real part and b is the imaginary part. On the complex plane, a is the horizontal coordinate and b is the vertical coordinate.

الوحدة التخيلية معرّفة بـi² = −1. العدد المركب هو z = a + bi، حيث a الجزء الحقيقي وb الجزء التخيلي. على المستوى المركب، a الإحداثي الأفقي وb الرأسي.

Rectangular form
z = a + b i
Re(z) = a, Im(z) = b
Conjugate
z̄ = a − b i
Reflect across the real axis
Modulus
|z| = √(a² + b²)
Distance from the origin
Argument
θ = tan⁻¹(b/a)
Adjust the quadrant of θ
2 · Algebra of complex numbers

Addition, multiplication, and division

Add/subtract real and imaginary parts separately. Multiply like binomials, then replace i² by −1. To divide, multiply numerator and denominator by the conjugate of the denominator.

اجمع/اطرح الأجزاء الحقيقية والتخيلية لوحدهم. اضرب كأنهم حدين، وبعدين استبدل i² بـ−1. للقسمة، اضرب البسط والمقام في مرافق المقام.

Addition
(a+bi) + (c+di) = (a+c) + (b+d)i
Multiplication
(a+bi)(c+di) = (ac−bd) + (ad+bc)i
Division
(a+bi)/(c+di) = (a+bi)(c−di)/(c²+d²)
Useful identity
z z̄ = |z|² = a² + b²
Always real and non-negative
→

Powers of i · قوى i

i¹ = i, i² = −1, i³ = −i, i⁴ = 1, then the pattern repeats every 4. To simplify iⁿ, divide n by 4 and use the remainder.

i¹ = i، i² = −1، i³ = −i، i⁴ = 1، وبعدها النمط بيتكرر كل 4. لتبسيط iⁿ، اقسم n على 4 واستخدم الباقي.

3 · Polar form

Modulus, argument, and De Moivre

Writing z = r(cos θ + i sin θ) makes multiplication, division, powers, and roots much easier. Here r = |z| and θ is the argument.

كتابة z = r(cos θ + i sin θ) بتسهّل الضرب والقسمة والرفع للقوى والجذور. هنا r = |z| وθ هي السعة.

Polar form
z = r(cos θ + i sin θ) = r eiθ
r = |z|, θ = arg z
Multiplication
z₁z₂ = r₁r₂[cos(θ₁+θ₂) + i sin(θ₁+θ₂)]
Multiply moduli, add arguments
Division
z₁/z₂ = (r₁/r₂)[cos(θ₁−θ₂) + i sin(θ₁−θ₂)]
Divide moduli, subtract arguments
De Moivre's theorem
zⁿ = rⁿ[cos(nθ) + i sin(nθ)]
n integer (also valid for rational with care)
nth roots
z1/n = r1/n[cos((θ+2kπ)/n) + i sin((θ+2kπ)/n)]
k = 0, 1, 2, …, n−1 gives n distinct roots
4 · Solved examples

أمثلة محلولة

Example 1 · division

Simplify (3 + 4i)/(1 − 2i).

Multiply by conjugate (1 + 2i): = (3+4i)(1+2i) / (1²+2²) Numerator = 3 + 6i + 4i + 8i² = 3 + 10i − 8 = −5 + 10i = (−5 + 10i)/5 = −1 + 2i
Example 2 · polar and De Moivre

Find (1 + i)⁶.

r = √(1²+1²) = √2, θ = 45° = π/4 1+i = √2(cos 45° + i sin 45°) (1+i)⁶ = (√2)⁶[cos 270° + i sin 270°] (√2)⁶ = 8, cos 270° = 0, sin 270° = −1 = 8(0 − i) = −8i
Example 3 · square roots

Find the square roots of i.

i = 1(cos 90° + i sin 90°), r = 1, θ = 90° √i = cos((90+360k)/2) + i sin((90+360k)/2), k = 0,1 k=0: cos45° + i sin45° = (1+i)/√2 k=1: cos225° + i sin225° = −(1+i)/√2

Argument quadrant · ربع السعة

tan⁻¹(b/a) only gives the reference angle. Check the quadrant: if a < 0, add or subtract 180°. If a = 0, the argument is ±90°. Always write θ in the correct quadrant.

tan⁻¹(b/a) بيعطي الزاوية المرجعية بس. اتأكد من الربع: لو a < 0، اضيف أو اطرح 180°. ولو a = 0، السعة ±90°. اكتب θ في الربع الصح دايمًا.

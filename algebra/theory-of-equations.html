1 · Polynomials

Degree, division, and the remainder theorem

A polynomial of degree n is f(x) = a₀xⁿ + a₁xⁿ⁻¹ + … + aₙ, with a₀ ≠ 0. Dividing f(x) by (x − c) gives a quotient and a remainder. The remainder theorem says the remainder equals f(c).

كثيرة حدود من الدرجة n هي f(x) = a₀xⁿ + a₁xⁿ⁻¹ + … + aₙ، بشرط a₀ ≠ 0. قسمة f(x) على (x − c) بتعطي خارج قسمة وباقي. نظرية الباقي بتقول إن الباقي = f(c).

Remainder theorem
f(x) = (x − c)Q(x) + f(c)
Remainder when dividing by (x − c)
Factor theorem
f(c) = 0 ⇔ (x − c) is a factor
Equivalent statements
Division algorithm
f(x) = d(x)Q(x) + R(x)
deg R < deg d
Multiplicity
f(x) = (x − c)mg(x), g(c) ≠ 0
m = multiplicity of root c
2 · Synthetic division

The fastest way to divide by (x − c)

Write the coefficients, bring down the first, multiply by c, add, repeat. The last number is the remainder; the others are the quotient coefficients. This is the practical tool for factor theorem questions.

اكتب المعاملات، انزّل الأول، اضربه في c، اجمع، وكرر. آخر رقم هو الباقي؛ والباقي معاملات خارج القسمة. دي الأداة العملية لأسئلة نظرية العامل.

Example 1 · synthetic division

Divide f(x) = 2x³ − x² + 2x − 1 by (x − 1). Find the quotient and remainder.

Coefficients: 2 −1 2 −1 Bring down 2 2×1 = 2; −1+2 = 1 1×1 = 1; 2+1 = 3 3×1 = 3; −1+3 = 2 Quotient: 2x² + x + 3; remainder: 2 Check: f(1) = 2 − 1 + 2 − 1 = 2 ✓
→

Sign trap · فخ الإشارة

For (x + c), use −c in synthetic division. For (2x − 1), divide by (x − 1/2) or use the factor theorem with c = 1/2. Do not forget missing powers: write 0 coefficients.

لو (x + c)، استخدم −c في القسمة التركيبية. ولو (2x − 1)، اقسم على (x − 1/2) أو استخدم نظرية العامل بـc = 1/2. متنساش القوى الناقصة: اكتب معامل 0.

3 · Roots and coefficients

Vieta's relations

For a quadratic ax² + bx + c = 0 with roots α, β:

للمعادلة التربيعية ax² + bx + c = 0 بجذور α وβ:

Quadratic · sum
α + β = −b/a
Quadratic · product
αβ = c/a
Equation from roots
x² − (α+β)x + αβ = 0
Sum of squares
α² + β² = (α+β)² − 2αβ

For a cubic x³ + px² + qx + r = 0 with roots α, β, γ:

للمعادلة التكعيبية x³ + px² + qx + r = 0 بجذور α وβ وγ:

Cubic · sum
α + β + γ = −p
Cubic · pair sum
αβ + βγ + γα = q
Cubic · product
αβγ = −r
Cubic from roots
x³ − S₁x² + S₂x − S₃ = 0
S₁ = sum, S₂ = pair sum, S₃ = product
4 · Transformations

Building a new equation from old roots

New roots · الجذور الجديدةReplace · استبدل
−α, −β, …x → −x, i.e. use f(−x) = 0
kα, kβ, …x → x/k, i.e. use f(x/k) = 0
α + h, β + h, …x → x − h, i.e. use f(x − h) = 0
α − h, β − h, …x → x + h, i.e. use f(x + h) = 0
1/α, 1/β, …x → 1/x, then clear fractions
α², β², …Use y = x², eliminate x
Example 2 · equation from roots

Find the quadratic equation whose roots are 2 + i and 2 − i.

Sum = (2+i) + (2−i) = 4 Product = (2+i)(2−i) = 4 − i² = 5 x² − 4x + 5 = 0
Example 3 · roots relation

If α, β are roots of x² − 5x + 6 = 0, find α² + β².

α + β = 5, αβ = 6 α² + β² = (α+β)² − 2αβ = 25 − 12 = 13

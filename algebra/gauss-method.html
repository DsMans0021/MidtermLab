Gauss's Method · طريقة جاوس

Gaussian elimination solves a system of linear equations by turning its augmented matrix into row-echelon form, then back-substituting. This page covers row operations, the algorithm, Gauss–Jordan, and Cramer's rule as a check.

حذف جاوس بيحل نظام معادلات خطية بتحويل المصفوفة الممتدة للصورة السلمية، وبعدين التعويض العكسي. الصفحة دي بتغطي عمليات الصفوف، الخوارزمية، جاوس–جوردان، وكرامر كتحقق.

1 · Linear systems

From equations to an augmented matrix

A linear system has the form a₁x + b₁y + c₁z = d₁, etc. Write only the coefficients in an augmented matrix. The vertical line separates the coefficient matrix from the constants.

النظام الخطي على شكل a₁x + b₁y + c₁z = d₁، إلخ. اكتب المعاملات بس في مصفوفة ممتدة. الخط الفاصل بيفصل مصفوفة المعاملات عن الثوابت.

Augmented matrix
[ A | b ]
Each row = one equation; each column = one variable's coefficients.

A system can have one solution, infinitely many solutions, or no solution. Gaussian elimination reveals which case you are in.

النظام ممكن يكون له حل واحد، أو عدد لا نهائي من الحلول، أو مفيش حل. حذف جاوس بيوضّح الحالة.

2 · Allowed moves

Elementary row operations

Operation · العمليةEffect · التأثير
Swap two rows · تبديل صفينRᵢ ↔ Rⱼ
Multiply a row by a nonzero constant · ضرب صف في ثابتRᵢ → kRᵢ
Add a multiple of one row to another · جمع مضاعف صف لصفRᵢ → Rᵢ + kRⱼ

These operations do not change the solution set. The goal is to create zeros below the pivot in each column.

العمليات دي مش بتغير مجموعة الحل. الهدف إنك تعمل أصفار تحت العنصر المحوري في كل عمود.

!

Do not · ممنوع

Do not multiply a row by zero. Do not add a multiple of a row to itself in a way that destroys the equation. Do not change the constants column independently.

ممنوع تضرب صف في صفر. وممنوع تجمع مضاعف صف عليه نفسه بشكل يدمّر المعادلة. وممنوع تغير عمود الثوابت لوحده.

3 · The algorithm

Gaussian elimination + back substitution

  1. Write the augmented matrix.
  2. Pivot on the first nonzero entry in column 1; swap if needed.
  3. Eliminate all entries below the pivot using row operations.
  4. Move to the next column and repeat until row-echelon form.
  5. Back-substitute from the last equation upward.
  6. Check by substituting into the original equations.
Row-echelon form
Leading 1s step down to the right
Zeros below each leading entry
Back substitution
Solve the last variable first, then move upward
Substitute known values into the row above
Gauss–Jordan
Continue to reduced row-echelon form
Zeros above and below each pivot → read solution directly
Cramer's rule
xi = det(Ai)/det(A)
Only if det(A) ≠ 0; good as a check
4 · Solved example

Solve a 3×3 system step by step

Example · Gaussian elimination

Solve: x + y + z = 6; 2x + y − z = 1; x − y + 2z = 5.

Augmented matrix: [ 1 1 1 | 6 ] [ 2 1 −1 | 1 ] [ 1 −1 2 | 5 ] R2 → R2 − 2R1: [0 −1 −3 | −11] R3 → R3 − R1: [0 −2 1 | −1] R3 → R3 − 2R2: [0 0 7 | 21] → z = 3 Back substitute R2: −y − 3(3) = −11 → y = 2 R1: x + 2 + 3 = 6 → x = 1 Solution: (x, y, z) = (1, 2, 3)

Substitute (1, 2, 3) into all three original equations. If one fails, the error is in the row operations, not the back substitution.

Quick rules

  • Swap rows freely.
  • Multiply a row by a nonzero constant.
  • Add a multiple of one row to another.
  • Pivot → eliminate below → repeat.
  • Back-substitute from the bottom.
  • Check in the original equations.

1 · Vectors

المتجهات

Vector
A = Axi + Ayj + Azk
Magnitude
A = √(Ax²+Ay²+Az²)
Unit vector
λ = A/A
Between points
AB = (xB−xA)i + …
Direction cosines
cos α = Ax/A, etc.
Identity
cos²α+cos²β+cos²γ = 1
Dot product
A·B = AB cos θ
Cross magnitude
|A×B| = AB sin θ
Projection of A on B
(A·B)/B
Angle
cos θ = (A·B)/(AB)
2 · Forces

القوى

Components
Fx = F cos θ, Fy = F sin θ
Resultant
Rx = ΣFx, Ry = ΣFy
Magnitude
R = √(Rx²+Ry²)
Direction
θ = tan⁻¹(Ry/Rx)
Two forces
R² = F₁²+F₂²+2F₁F₂cos α
Force along AB
F = F λAB
Perpendicular forces
R = √(F₁²+F₂²)
Equilibrium
ΣF = 0

4 · Equilibrium

الاتزان

Particle 2D
ΣFx = 0, ΣFy = 0
Rigid body 2D
ΣFx = ΣFy = ΣM = 0
Particle 3D
ΣFx = ΣFy = ΣFz = 0
Rigid body 3D
ΣF = 0, ΣM = 0
Two-force member
Equal, opposite, collinear
Truss joint
ΣFx = 0, ΣFy = 0
Roller
One normal reaction
Pin
Two force components
5 · Wrench

المفتاح

Resultant
R = ΣF
Moment
MO = Σ(r×F)
Pitch
p = (R·MO)/R²
Wrench couple
Mw = pR
Central axis point
r₀ = (R×MO)/R²
Central axis
r = r₀ + λR
Pure couple
R = 0, M ≠ 0
Single force
R·MO = 0, R ≠ 0

Before you submit · قبل التسليم

1) Units N and N·m. 2) Signs consistent. 3) FBD complete. 4) N found from equilibrium, not assumed mg. 5) Cross-product order correct. 6) Moment arm perpendicular. 7) Truss member sign interpreted. 8) Belt angle in radians. 9) Central axis avoids division by zero. 10) Final check by substitution.

1) الوحدات N وN·m. 2) الإشارات متناسقة. 3) FBD كامل. 4) N من الاتزان مش بافتراض mg. 5) ترتيب الضرب الاتجاهي صح. 6) ذراع العزم عمودي. 7) إشارة عضو الجمالون متفسرة. 8) زاوية السير بالراديان. 9) المحور المركزي بدون قسمة على صفر. 10) تحقق نهائي بالتعويض.

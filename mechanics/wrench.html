Mechanics · Topic 05 · Wrench

The Wrench · المفتاح

Any force system can be reduced to a force and a couple at a point. When the couple is parallel to the force, the system is a wrench: a force plus a parallel couple. This page covers the reduction, pitch, and central axis.

أي نظام قوى يمكن اختزاله لقوة وزوج عند نقطة. لما الزوج يكون موازي للقوة، النظام بيبقى مفتاح: قوة وزوج موازي. الصفحة دي بتغطي الاختزال، الخطوة، والمحور المركزي.

1 · Reduction

Force–couple system at a point

Choose a reference point O. The resultant force is the vector sum of all forces. The resultant moment is the sum of the moments of all forces about O. This pair (R, MO) is equivalent to the original system.

اختار نقطة مرجعية O. المحصلة هي مجموع القوى المتجه. والعزم المحصل هو مجموع عزوم كل القوى حول O. الزوج (R, MO) مكافئ للنظام الأصلي.

Resultant force
R = ΣF
Resultant moment
MO = Σ(r × F)
Equilibrium
R = 0 and MO = 0
Single force
R ≠ 0 and R·MO = 0
Moment perpendicular to R
→

Three possible results · ثلاث نتائج

If R = 0 and M = 0: equilibrium. If R = 0 and M ≠ 0: a pure couple. If R ≠ 0: a single force, or a wrench when M has a component parallel to R.

لو R = 0 وM = 0: اتزان. لو R = 0 وM ≠ 0: زوج صافي. لو R ≠ 0: قوة واحدة، أو مفتاح لو M له مركبة موازية لـR.

2 · The wrench

Pitch and parallel couple

The component of M parallel to R cannot be removed by moving the line of action. It becomes the wrench couple pR. The scalar p is the pitch: the advance per full turn, in units of length.

المركبة الموازية لـR من M مينفعش تتشال بنقل خط العمل. بتبقى زوج المفتاح pR. القيمة p هي الخطوة: المسافة لكل لفة كاملة، بوحدات الطول.

Pitch
p = (R·MO) / R²
Wrench couple
Mw = pR
Parallel part
M∥ = (R·MO/R²) R
Perpendicular part
M⊥ = MO − M∥

If p = 0, the wrench reduces to a single force. If R·MO = 0, the force and couple are perpendicular, so the system is a single force whose line of action is offset from O.

لو p = 0، المفتاح يختزل لقوة واحدة. لو R·MO = 0، القوة والزوج متعامدين، فالنظام قوة واحدة خط عملها بعيد عن O.

3 · Central axis

Where the wrench acts

The central axis is the line along which the wrench force acts. Every point on it gives the same minimum moment parallel to R. The point closest to the origin is r₀ = (R × MO)/R².

المحور المركزي هو الخط اللي قوة المفتاح بتأثر عليه. كل نقطة عليه بتعطي نفس العزم الموازي لـR. أقرب نقطة للأصل هي r₀ = (R × MO)/R².

Central axis
r = (R × MO)/R² + λR
λ is a scalar parameter; the line direction is R
Symmetric equations
(x−x₀)/Rx = (y−y₀)/Ry = (z−z₀)/Rz
Use only for nonzero components
!

Zero components · المركبات الصفرية

If a component of R is zero, do not divide by it. Write the axis as two plane equations instead, or use the parametric form r = r₀ + λR.

لو مركبة من R = صفر، متقسمش عليها. اكتب المحور كمعادلتين مستويتين، أو استخدم الصورة البارامترية r = r₀ + λR.

4 · Solved example

Reduce a system and find the wrench

Example · wrench

Given R = 8k N and MO = −9i + 7.2k N·m, find the pitch, wrench, and central axis.

R² = 64 p = (R·MO)/R² = (8 × 7.2)/64 = 0.9 m Wrench couple = pR = 0.9(8k) = 7.2k N·m r₀ = (R × MO)/R² = (1/64)(0, 72, 0) = (0, 1.125, 0) m Axis: x = 0, z = 0, y = 1.125 (a line parallel to the z-axis) Wrench = (8k N, 7.2k N·m)
→

Interpretation · التفسير

The force acts along the vertical line through (0, 1.125, 0), with a parallel couple of 7.2 N·m. The pitch 0.9 m means the equivalent screw advances 0.9 m per revolution.

القوة بتأثر على الخط الرأسي المار بـ(0, 1.125, 0)، مع زوج موازي 7.2 N·m. الخطوة 0.9 m معناها إن المسمار المكافئ بيتقدم 0.9 m لكل لفة.
